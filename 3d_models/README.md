# 3D Printable Enclosure for cwmera

This folder contains the CAD files and 3D printable models (`.stl`, `.step`) for the `cwmera` body and front plate.

### Recommended 3D Print Settings
* **Material:** PLA, PLA+, or PETG (Black or White to match the monochrome aesthetic)
* **Layer Height:** `0.16mm` or `0.20mm` for smooth detail
* **Infill:** `15% - 20%` (Gyroid or Grid)
* **Perimeters/Walls:** 3
* **Supports:** Tree supports recommended only for button holes and connector cutouts
* **Hardware:** M2 or M2.5 screws for securing the display and front plate
